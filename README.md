Toque y Fama - Java
Juego de lógica tipo Mastermind implementado en Java como proyecto académico de Programación Orientada a Objetos.

El jugador debe adivinar un número secreto de 4 dígitos. El sistema responde con:

Toque: dígito correcto pero en posición incorrecta
Fama: dígito correcto en posición correcta

🛠️ Stack
Java
POO (Clases, encapsulamiento)
Estructuras de datos (Arrays, ArrayList)
Lógica de validación y control de flujo

✨ Funcionalidades
Generación aleatoria del número secreto
Validación de entrada del usuario
Conteo de Toques y Famas
Contador de intentos

🚀 Cómo ejecutarlo
bash
javac Toque.java
java Toque

🧠 Qué aprendí
Separación de responsabilidades en clases
Validación de datos de entrada
Lógica de comparación y búsqueda
